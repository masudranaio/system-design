Case study · High-level design

Amazon Locker: capacity and reservation

Why reservations are the hot path

A locker network has no elastic capacity: a compartment is either free or it isn't, and two couriers must never be handed the same one. At Amazon's scale that check runs at a peak near 500K QPS against a dataset that changes every few seconds, so it can't be served from the same store that holds package lifecycle history. This applies caching strategies under a correctness constraint rather than a latency one.

  • Reserve takes a short-lived hold, not a booking — an abandoned courier app must not strand a compartment.
  • Availability is read far more than written, roughly 40:1 at peak.
  • A stale free answer is a failed pickup; a stale busy answer only costs a retry.

Scope

What actually changes

Diagram appearance

Bright fills, bold 15px near-black labels, 2px strokes, right-angle routing (dagre → elk), always-paper canvas, auto legend, fit-to-width, panel 32rem → 40rem.

Diagram plumbing

One tested pure function retints D2's SVG at render time. Your six authored hexes become semantic keys — zero edits across 392 nodes in 16 MDX files, and ~100 lines of dark-mode !important overrides get deleted.

Color system

One accent becomes: magenta identity + four track lines + three semantic states. Track color appears in the sidebar, homepage cards and lesson kicker, so color tells you where you are.

Typography

Serif body → Source Sans 3 at 17/1.75; headings → Archivo; measure 100ch → 90ch. Also fixes an existing bug where .font-mono shared a selector with h1–h6, so every eyebrow was being styled by the heading rule.

Tables

Header band, zebra rows, tabular numerals, own scroll container. Five MDX files have raw tables that currently render completely unstyled.

Chrome

Radius 4px → 10px, content on a white card, sidebar cards with icon chips + lesson counts, TOC reading-progress bar, magenta focus rings everywhere.

Not in scope

Callout/admonition component, code syntax highlighting, progress persistence, search. Recorded in the spec so they don't get absorbed silently.
